# Private native execution

English | [中文](README.zh.md)

This package supplies two independent owner-only execution interfaces. `NativeSessionDriver` retains its protected text-only journal and rejects tools. `prepareOwnedGenerationSource` binds a real native activity to one immutable product binding without widening that driver.

The owner prepares strict model calls before `ownerCtx.agents.create`, passes `protectedModelCalls` to creation, retains the returned actual handle, and attaches it once. `isPreparedOwnedGenerationSource` verifies the exact owner, session and role before creation effects. Journal attachment also verifies that these exact protected calls were present at the native Agent's birth. A bare Agent, copied handle, structural provider or JSON preparation cannot supply that authority. Ordinary work and derived child sources have no tools; a main source retains exactly one actual `dsh_bot_delegate` definition. Main attachment may precede registration so creation can verify a blank tool registry; every start and request requires the exact registered definition. The whole actual tool definition is frozen, including parameters, output schema, rendering and content callbacks, presentation metadata, concurrency policy and timeout. Accessor policies are rejected. Preparation captures its route, initialization, complete plan and callbacks before effects.

Attachment accepts a blank log or the exact declared initialization prefix: `permission/preset`, `sandbox/mode`, then `approval/policy`, with identical values and no other events. The owner supplies that policy snapshot before creation. Any prior input, turn, model call or tool history rejects attachment. Historical attachment requires the exact owner journal described below; an unsealed historical Agent remains unusable.

`start(binding, input)` synchronously returns an opaque generation. Bindings retain the exact UUID string `configVersion` and positive integer generation and epoch fields. The source owns the exact native input, original activity counter, driver promise, cancellation controller, request objects and observed assistant streams. A synchronous inbox failure still retains an inspectable UNKNOWN generation. An UNKNOWN generation cannot be reused or replayed.

`inspect` reports local return independently from remote settlement. A receipt requires the original activity to return, complete actual response finish and usage for every dispatched request, and readback of the exact flushed input/turn/assistant window. Default assembler finish, missing provider usage, idle, a turn ending and cancellation alone provide no receipt. Explicit observed zero counts are valid. Only `isOwnedGenerationReceipt(receipt, source, exactBinding)` verifies receipt identity; serialized or copied receipts fail.

`isCurrent` checks receipt authority and exact product lifetime. `canDispatch` separately fences requests, including after asynchronous authentication. `cancel` fences that generation before its first await and aborts its captured original controller; it cannot stop a replacement activity. A fully observed response can settle after cancellation only when its original activity returns and the durable window agrees. Otherwise remote execution remains UNKNOWN. Settlement reports model response and accounting evidence, not completion of a product goal.

The keyless tests mount the real Loader, AgentLoop, persistence, tools and strict provider with an offline SSE transport. They verify native ownership and settlement mechanics; they do not establish real model behavior or remote service cancellation.

The owner opens `openOwnedGenerationJournal` in a private directory before preparation and native creation. A new journal rejects both a live existing Session and retained native history, including an otherwise blank initialization prefix. The journal owns an exclusive native flock and synchronous durable SQLite intent rows. Format 2 binds the original Session header, route, initialization, complete tool policy, original creation intent, complete input and binding, final request and wire digests, actual response finish and usage, and the returned original activity. It does not migrate earlier journal formats or authorize legacy Homes. The incremental host-only `nativeActivityIntegrity` projection carries exact event order and chain coordinates without exposing ownership. Before every wire dispatch, the source reads the actual durable chain again after asynchronous preparation and authentication; a projection cache alone cannot authorize transport.

For a known restart, the owner opens the same journal with `create: false`, prepares protected calls, invokes actual `ownerCtx.agents.resume`, and retains the new real handle for the same Session id. The journal rejects unfinished or altered history before resume. Main resume requires its exact actual delegate definition during preparation so policy mismatch rejects before factory effects. Attachment accepts only the known checkpoint and native constructor continuation marker. `selectOwnedGenerationHistory(journal, ownerCtx, fullOriginalBinding, authority)` reads the complete sealed history and mints an opaque original selector. `await source.restoreKnown(selector)` reads the original sealed window again and returns a new source-owned historical generation without sending the old input. `isOwnedGenerationHistorySelector` rejects copied selectors and changed original operation, nonce or lease. Its separate live read authority can admit the exact historical receipt after product epochs change, while `isCurrent` and `canDispatch` still govern new requests. The older `restore(binding)` path retains its strict current-binding requirement. New input requires a strictly newer generation.

A parent work source may opt into exactly one actual delegate definition with `workDelegate`; its journal explicitly uses `toolPolicy: 'delegate'`. `workDelegate.plannedBinding` pins the complete pre-reserved start binding: operation, nonce, actual input id and digest, slot lease and all product coordinates. `plannedBinding` supplies the same complete admission for zero-tool work or a child without adding delegation rights. Only an actual original delegate call can derive `prepareOwnedChildGenerationSource`; copied sources, fabricated generations, JSON lineage and recursive children cannot. The branded child preparation supplies the actual `parentAgent` for native creation and verifies live runtime ownership and sealed birth lineage. Its zero-tool dispatch rechecks the captured original parent and product grant after every asynchronous phase. After the prior original receipt, `planOwnedWorkGenerationSource(source, ownerCtx, fullNextBinding)` admits a new complete plan, including new operation, nonce, input and lease for g2; a nine-field subset or conflicting same-generation plan cannot authorize it. The product owns shared work-slot reservations and includes grant and lease authority in its dispatch guard.

A known child reopens through `await prepareOwnedKnownChildGenerationSource(actualResumedParentSource, restoredOriginalParentGeneration, childOptions)`. The native source checks the complete sealed original parent input and binding, actual delegate call and original child journal before factory effects. The resulting preparation retains the actual resumed `parentAgent` for the same child Session id. A serialized parent id or ordinary work preparation cannot restore that child. Its new complete plan can admit a new child generation under current owner authority; it never replays its sealed original input. A replacement native parent activity invalidates the historical preparation.

Restoration may retain its exact sealed original complete plan through `historicalPlan: genuineHistorySelector`, including when ordinary current-binding checks reject its old epochs. The selector and exclusive journal must agree on the whole original plan before native factory effects. That plan cannot start or replay; the native journal rejects consumed generations. The owner waits for actual user continuation, durably reserves its complete new input, operation, nonce and lease, then calls the same full planner under current `isCurrent` and `canDispatch`. It never invents a future input during restore.

Official sandbox and approval hooks may append a native runtime-context snapshot beside the original operator input. AgentLoop records the exact message object and event sequence under the original activity before hooks can copy or relabel it. Settlement validates these native-attested events against the whole durable window and seals them. `getOwnedGenerationReceiptInputWindow(receipt, source, fullBinding)` returns frozen original input id, window coordinates and runtime-context ids only for the exact source-branded receipt. Product response attribution may omit only those attested ids. A JSON `source.kind`, an extra operator message or a copied native message supplies no authority.

Native archive uses the actual Workspace registry and its shared `ArchivedSessionGate`. The owner mounts it through `mountOwnedGenerationArchiveGate(ownerCtx)` and admits `admitOwnedGenerationControl(source, originalGeneration, ownerCtx, fullBinding, authority)` before product invalidation. The control supplies only exact-original `inspect`, `cancel` and `archive`; it cannot start or attach a source. Its pinned synchronous `isAuthorized` callback validates the current actual owner grant and fiber, independently from old epochs. Its pinned `isDispatchFenced` callback verifies the product's durable dispatch fence. Archive synchronously fences the native journal and stops only the captured original activity, rechecks full durable history, then calls actual `workspaceRegistry.archiveSession` with guards before and after asynchronous effects. UNKNOWN can be archived after local return, but retains UNKNOWN accounting and cannot reopen.

A genuinely empty sealed creation uses `admitOwnedBlankSessionControl(source, ownerCtx, originalCreationIntent, authority)`. That intent is the immutable actual pre-native creation data with original operation and nonce; it does not invent a model generation or main task coordinates. The complete journal, original initialization and native activity counter must remain empty throughout archive. A racing start invalidates the control without cancelling that new generation. After exclusive known-history reopening and actual same-id protected attachment, `unarchiveOwnedGenerationSource(source, ownerCtx, authority)` verifies the entire journal and original native checkpoint before and after actual unarchive. It clears the native dispatch fence only after successful verification. UNKNOWN, legacy history, copied capabilities and dead grants remain closed.
