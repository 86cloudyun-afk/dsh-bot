# Private native execution

English | [中文](README.zh.md)

This package supplies two independent owner-only execution interfaces. `NativeSessionDriver` retains its protected text-only journal and rejects tools. `prepareOwnedGenerationSource` binds a real native activity to one immutable product binding without widening that driver.

The owner prepares strict model calls before `ownerCtx.agents.create`, passes `protectedModelCalls` to creation, retains the returned actual handle, and attaches it once. `isPreparedOwnedGenerationSource` verifies the exact owner, session and role before creation effects. A bare Agent, copied handle, structural provider or JSON preparation cannot supply that authority. Ordinary work and derived child sources have no tools; a main source retains exactly one actual `dsh_bot_delegate` definition. Main attachment may precede registration so creation can verify a blank tool registry; every start and request requires the exact registered definition.

Attachment accepts a blank log or the exact declared initialization prefix: `permission/preset`, `sandbox/mode`, then `approval/policy`, with identical values and no other events. The owner supplies that policy snapshot before creation. Any prior input, turn, model call or tool history rejects attachment. Historical attachment requires the exact owner journal described below; an unsealed historical Agent remains unusable.

`start(binding, input)` synchronously returns an opaque generation. Bindings retain the exact UUID string `configVersion` and positive integer generation and epoch fields. The source owns the exact native input, original activity counter, driver promise, cancellation controller, request objects and observed assistant streams. A synchronous inbox failure still retains an inspectable UNKNOWN generation. An UNKNOWN generation cannot be reused or replayed.

`inspect` reports local return independently from remote settlement. A receipt requires the original activity to return, complete actual response finish and usage for every dispatched request, and readback of the exact flushed input/turn/assistant window. Default assembler finish, missing provider usage, idle, a turn ending and cancellation alone provide no receipt. Explicit observed zero counts are valid. Only `isOwnedGenerationReceipt(receipt, source, exactBinding)` verifies receipt identity; serialized or copied receipts fail.

`isCurrent` checks receipt authority and exact product lifetime. `canDispatch` separately fences requests, including after asynchronous authentication. `cancel` fences that generation before its first await and aborts its captured original controller; it cannot stop a replacement activity. A fully observed response can settle after cancellation only when its original activity returns and the durable window agrees. Otherwise remote execution remains UNKNOWN. Settlement reports model response and accounting evidence, not completion of a product goal.

The keyless tests mount the real Loader, AgentLoop, persistence, tools and strict provider with an offline SSE transport. They verify native ownership and settlement mechanics; they do not establish real model behavior or remote service cancellation.

The owner opens `openOwnedGenerationJournal` in a private directory before preparation. The journal owns an exclusive native flock and synchronous durable SQLite intent rows. It binds the original Session header, route, initialization, exact tool schema and output contract, complete input and binding, final request and wire digests, actual response finish and usage, and the returned original activity. The incremental host-only `nativeActivityIntegrity` projection carries exact event order and chain coordinates without exposing ownership. Before every wire dispatch, the source reads the actual durable chain again after asynchronous preparation and authentication; a projection cache alone cannot authorize transport.

For a known restart, the owner opens the same journal with `create: false`, prepares protected calls, invokes actual `ownerCtx.agents.resume`, and retains the new real handle for the same Session id. The journal rejects unfinished or altered history before resume. Main resume requires its exact actual delegate definition during preparation so schema mismatch rejects before factory effects. Attachment accepts only the known checkpoint and native constructor continuation marker. `await source.restore(exactHistoricalBinding)` reads the original sealed window again and returns a new source-owned historical generation; it never sends the old input. Its receipt retains the full original operation, nonce and lease fields. New input requires a strictly newer generation.

A parent work source may opt into exactly one actual delegate definition with `workDelegate` and stable planned binding coordinates; its journal explicitly uses `toolPolicy: 'delegate'`. Complete start bindings still retain all execution fields. Only an actual original delegate call can derive `prepareOwnedChildGenerationSource`; copied sources, fabricated generations, JSON lineage and recursive children cannot. The branded child preparation supplies the actual `parentAgent` for native creation and validates both live runtime ownership and durable lineage. Its zero-tool dispatch rechecks the captured original parent and product grant after every asynchronous phase. The owner can plan the next parent work generation with `planOwnedWorkGenerationSource` only after the prior original receipt. The product owns shared work-slot reservations and must include grant and lease authority in its dispatch guard.
