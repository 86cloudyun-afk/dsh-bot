# DSH Bot 原生插件安装

当前为开发版本，完整验收尚未通过，正式 v1 尚未交付。

使用前需要正常工作的官方 DSH。首个验证基线为 `@deepseek-ai/dsh@0.2.0-rc.2`。插件不包含宿主或凭据，不启动独立应用，不改写 DSH 本体。

合格包将通过官方插件管理器安装：选择“安装插件包”，使用对应 Release 的插件 tgz 或本地已解包目录；启用后在原有侧栏打开“Bot 工作台”。具体版本、安装结果与操作验证将在正式验收后补齐。

[旧独立软件已完全作废](history/standalone-void.md)，其安装器及专用 profile 不适用于本插件。
