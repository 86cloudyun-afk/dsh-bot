# v1.3.0 Bot 空间 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在官方 DSH 内交付有设计感的专用 Bot 私聊、群聊和协作空间。

**Architecture:** 专用 keyed panel 复用官方 SessionProvider 和 conversation.content embedded factory，群消息和协作使用现有真实业务控制器。新增精确群轮停止；单浏览器 factory 由独立空间源码确定性内联。

**Tech Stack:** 官方 DSH 0.2.0-rc.2、React 公共 renderer props、原生插件 Node ESM、纯 CSS、node:test、Playwright；不增加产品依赖。

**Spec:** `docs/superpowers/specs/2026-10-11-v1.3-bot-space-design.md`

## Global Constraints

- 官方未修改的 DSH `0.2.0-rc.2` 原生插件；不创建独立 Host，不修改 DSH 本体。
- 产品目标版本 `1.3.0`，schema 2、clientProtocol 2；保留原身份、历史、回执和 UNKNOWN。
- 每 Bot 15 工作槽、一级子工作、可撤销共享和原生审批继续有效。
- 受控提供者／外部模型请求为零／不访问用户 Host。
- v1.2.0 和所有历史分发字节保持；PR #1 关闭未合并。
- Root 独占 git/index/commit/remote mutations；工作者只编辑指定文件，不派生子代理。
- 新空间 panel `dsh-bot.space`，Session 子槽 `dsh.bot-space.conversation`，样式只在 `dsh-bot-space`／`bs-` 内。

## Review Focus

1. 两个同名 Bot、切换后迟到 ready／command：只显示当前稳定 ID，不泄漏旧引用或打开旧会话。
2. 创建原生 channel 仍在等待时停止群轮：不得在 stop 意图之后开始新的 followup／成员／回复。
3. 群消息提交中切到另一群或修改正文：仅清理原群原提交草稿，UNKNOWN 不换 ID 重发。
4. 群会话显示成员私人任务或提前显示独立意见：归属来自 meetings.actions，独立意见正常封存。
5. 宿主窄窗口、中文输入法和审批 takeover：专用布局可操作，原生 composer／工具审批链保持。
