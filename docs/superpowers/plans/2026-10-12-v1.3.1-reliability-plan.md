# v1.3.1 Bot 空间与状态读取修复计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Root owns commits, remote mutations and publication.

**Goal:** 修复已复现的五处现有行为缺陷，保留原对象、来源与操作回执，并讨论下一版真正新增的能力。

**Architecture:** 延续 v1.3 的官方原生插件、schema 2 与 clientProtocol 2。通知在返回 DTO 前按自身资源及来源过滤；记忆来源按真实人类操作区分；界面只修复读取错误、原生引用恢复与输入法生命周期。

**Tech Stack:** Node ^22.19.0 || >=24、官方 DSH 0.2.0-rc.2、现有原生 SDK、现有 React factory 与 node:test。

**Spec:** ../specs/2026-10-11-v1.3-bot-space-design.md；本次具体修复设计见下列任务。

## Global Constraints

- 官方 DSH 本体不修改，不新增服务、依赖或凭据。
- 各 Bot 独立记忆；跨 Bot 默认只读、授权持续有效且可撤销。
- UNKNOWN 不自动重放；保留原会话、请求、工具调用、操作 ID 与日志。
- 每 Bot 15 工作槽、一级子工作；读取、重试引用与浏览不启动新模型工作。
- 验证只用隔离官方 profile 与本地受控提供者；外部模型调用为零，不访问用户 Host。
- v1.3.0 及全部旧包、标签和历史证据保持原字节，PR #1 不合并。

## Review Focus

- 外 Bot 通知不可读时，只过滤该通知，自己的通知、snapshot、briefing 仍可正常读取。
- 遗忘同一原生日志来源仍阻止自动重摄入；不同人类 operationId 不误判为同一来源。
- 引用 ready 失败后显式重试保留同一原 session；取消、断线、换群及世代变化立即失效。
- 输入法结束事件丢失、迟到事件及群／连接切换不会永久禁用新输入或误触发发送。
- snapshot 网络失败与成功读取后身份失效分别反馈；已创建会话不重新创建。
