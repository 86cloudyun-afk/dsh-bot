# v1.1 原生 Bot 管理与协作知识升级 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 官方原版 DSH 插件支持 Bot 自身会话管理，协作与知识增强及日常简报定时。
**Architecture:** 保留原 TaskController/Broker 原生执行链；schema 2 在同一原子 KV 记录内迁移，权限由真实 process-local principal 统一检查。新资料、记忆、模板、助理为独立 controller，由原 service/plugin 统一接入，客户端保持五个页签。
**Tech Stack:** Node ^22.19.0 || >=24，ES modules，官方 DSH 0.2.0-rc.2，原生 JSON KV，React additive slots。
**Spec:** ../specs/2026-10-09-v1.1-native-upgrade-design.md 与 assistant/collaboration/knowledge/owned-control 子规格。

## Global Constraints
- 官方 DSH 0.2.0-rc.2；DSH 本体不修改，不分发 Host 或 SDK。
- Node ^22.19.0 || >=24；Linux x64 与 macOS arm64 使用同一分发包验收。
- 1.1.0 / clientProtocol 2；沿用 dsh_bot_v1 KV version 1 的 state/current。
- UNKNOWN 保留身份、槽位和原请求，零自动重放；每 Bot 15 工作槽与一级子工作。
- native 工具默认允许，原生审批有效；跨 Bot 共享与控制持续有效且可撤销。
- 查询／检索／简报／模板实例化／诊断／迁移不额外调用模型。

## Review Focus
- 迁移写入失败、未来或恶意 schema：拒绝且不覆盖，备份校验失败不能继续。
- 来源撤销和未揭示会议意见：通知／检索／新执行／导入都不能清除限制。
- 崩溃与原生丢回执：保留真实 task/attempt/operation IDs，不替换重试。
- 多页面并发草稿：所有编辑 CAS，失败原草稿保留。
- 长时间停机、夏令时和时钟回拨：有界游标、至多最近一次补做、不延长恢复窗口。
