# v1.2 连续使用与恢复可靠性实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox syntax for tracking.

**Goal:** 落实已复现的恢复、状态与来源问题，并提升已有聊天和跨块检索的实际使用体验。

**Architecture:** 复用现有 Policy、Controller、snapshot 和原生会话入口；各任务拥有独立源文件，集成阶段统一构建、验收与版本发布。

**Tech Stack:** Node ESM、既有 DSH rc.2 SDK、现有 React 客户端与 Playwright 受控验收。

**Spec:** `docs/superpowers/specs/2026-10-11-v1.2-continuity-design.md`

## Global Constraints

- 未修改官方 DSH `0.2.0-rc.2`；Node `^22.19.0 || >=24`；Linux／macOS。
- schema 2／协议 2、15 槽及一级子工作不变，UNKNOWN 不自动重放。
- 原 ID、日志、资料块与回执保留；不访问用户 Host、不请求外部真实模型。
- 不新增依赖、主导航或权限配置；只改任务拥有的文件，提交和发布由主执行者统一处理。

## Review Focus

- 读取未使用的旧群消息导致无关授权撤销阻塞工作：仅记录真正返回／消费的消息。
- 浏览器双记录部分保存和完成后清理失败：原请求始终可查，确定回执不误报未知。
- 选择已有聊天期间对象归档或 Bot 删除：重新核对稳定 ID 与当前绑定。
- Unicode 归一化和资料块边界：引用精确，邻块真实匹配，limit 与稳定排序不变。
- 旧子尝试与旧提醒已完成：新停止或内容编辑不能改写后续尝试或重复触发。
