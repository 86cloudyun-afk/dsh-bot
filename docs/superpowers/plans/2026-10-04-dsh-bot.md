# DSH Bot Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. 当前 agent 是唯一工程 owner，原主控负责最终验收与合并。

**Goal:** 交付可持久恢复、可审查的原生 DSH 控制层候选，缺失原生能力明确阻断。

**Architecture:** SQLite 单写者保存身份、授权、责任和短事务 outbox；DSH adapter 只封装公开冷读。Host 统一命令，所有原生副作用经过能力门，当前版本不 dispatch；无另一套 Agent 执行器。

**Tech Stack:** Node.js 22.16+、node:sqlite、ES modules、零 runtime dependencies、Node test runner、静态四入口 UI、可选 Cordis peer。

**Spec:** `docs/spec-v0.2.1.md`；能力限制 `docs/host-capabilities.md`。

## Global Constraints

- “插件不引入第二套模型运行框架。”
- “首版不物理删除。”
- “unknown 不自动重放。”
- “不可变快照不冻结撤权。”
- “首版默认人类最终验收。”
- “任何六项硬需求未通过都留为发布阻断项，不删需求降低标准。”
- 1 human / 1 host / 多 Bot / 内部群 / 手动会议任务；不新增平台、定时 routines 或多租户。
- 不启动生产 DSH，不读凭据和原生私有 Session，不改 core，不付费调用，不复制第三方实现。测试与文档验证均 guard。
- 新私有 GitHub 仓库和 draft PR 已授权；原主控唯一合并。

## Review Focus

- actor + nonce 重用但目标 / 世代 / 内容变化应冲突，不得重复插入 operation。
- receipt 丢失、重启和 lease 到期不得自动重放 unknown 效果。
- await 后撤权 / task revision / 成员世代变化，旧结果不得提交或公开。
- timeout 不能释放真实未知资源；复合资源全有全无领取，不跨 await 持部分锁。
- 双群双会议材料不串；canonical 去重；仅显式人类 recipient 路由。
