# v1.1 记忆管理、资料检索与导入导出

状态：待评审设计。全局约束见 [总规格](2026-10-09-v1.1-native-upgrade-design.md)。

## 1. 记忆管理与上下文

记忆页继续按 Bot 管理，增加搜索、直接编辑、分类筛选、更新时间和固定重要记忆。复用已有 memory.search／memory.write／memory.forget 和版本检查，新增 pinned 布尔元数据，修改使用开始编辑时的 expectedVersion；其他页面更新不能覆盖草稿。

新分类为 fact、preference、decision、responsibility；旧版已有的其他字符串分类原样保留并显示“其他”，不静默改写。正文仍最多 8192 字符。固定项优先于普通项，但总上下文预算不变，不能承诺无界固定。每 Bot 最多固定 8 条，超限明确拒绝。Bot 新增 memoryRevision，任一记忆写入、遗忘、固定或批量导入均递增；该版本独立于 Bot 配置版本。

新会话／新轮仍自动带入本 Bot 身份、相关长期记忆和未完成任务，最大 12000 字符。先预留系统说明、身份／职责和最多 1200 字符的未完成任务完整摘要项，再选择记忆；记忆最多 8 个固定项＋10 个其他项，每项为不超过 400 Unicode 码点的明确预览，记忆段最多 6000 字符且受总剩余预算约束。没有相关查询时其他项取最近 4 条。先以完整序列化项预算，再对实际带入项 noteRead，避免对未注入项记录依赖、截断 JSON 或吞掉任务摘要；长职责减少可带入记忆，不以最后截断整个上下文解决超限。详细记录通过工具按需查询，界面可查看实际带入的记忆摘要与未带入原因。

固定不会越过当前读取权限、来源撤销或会议封存。编辑既有记忆必须保留其 source、lineage、origins 和遗忘标记，新增修改来源追加，不能把人类编辑当成清除旧权限限制的方式。遗忘仍保留日志／来源标记，自动整理不能立刻由相同已遗忘来源重新加入；本版不新增后台自动合并或自动删除记忆。

## 2. 资料收录

资料属于某个 Bot，提供正文粘贴、UTF-8 `.txt`／`.md` 上传，以及明确选择的原生会话文本片段。浏览器粘贴与文件上传是 human-only；Bot 可通过所属资料写工具提供派生正文，但 source 必须由服务端根据已认证的真实 Bot 会话、lineage 和当前 readDependencies 生成，不能从 caller 提供的 `kind:human` 标签获得人类来源。PDF／Office 经 DSH 原有工具提取正文后收录；不执行资料中的 HTML、脚本或指令，不抓取远程 URL。

每份资料为不可变正文：docId、botId、标题、媒体类型、原始文件名或来源说明、contentHash、版本、createdAt、source、origins、archived 和 chunk 元数据。修订正文形成新 docId，并保留旧来源；本版不提供隐式覆盖原文。归档保留身份、引用和额度。

具体限额：每份正文最多 64 KiB UTF-8；每 Bot 最多 100 份、全 profile 最多 500 份；正文与元数据累计每 Bot 2 MiB、profile 8 MiB，归档项同样计入。超限拒绝整个收录，不截断正文、不丢旧记录。记忆的正文／元数据另计每 Bot 2 MiB、profile 8 MiB，条目上限每 Bot 2000、profile 10000；旧数据已超过新限额时完整保留，仅阻止净增长写入，不以升级失败／删数据来处理。

原生会话片段输入 `{sessionId,eventSeq,partIndex,startOffset,endOffset}`，服务端从真实 event 中读取指定文本部分，验证调用者权限及 UTF-16 边界，禁止切开代理对，引用精确范围；客户端不能以 supplied text 冒充该 event。保存原会话 lineage、版本／摘要与来源权限，冷读不启动 Agent。手动粘贴和上传保存为人类提供资料，不假装来自某条原生事件。

## 3. 检索与真实引文

正文分块优先保持标题／段落边界，每块最多 800 Unicode 码点，无重叠；记录原文 UTF-16 start／end 和从 1 开始的行号。chunkId 由 docId、contentHash 与范围确定，原文不经规范化改写。

词法查询最多 500 字符，默认返回 8 块、最多 20 块。只在评分副本做 NFKC、大小写处理，Unicode 字母／数字 token 与中日韩双字片段结合；单字符查询保留单字符。短语、标题、章节命中加权，最终以 docId／原范围稳定排序。

先按当前权限和会议屏障过滤再评分，不以排名／命中计数泄漏隐藏资料。结果包含 docId、chunkId、真实整块 excerpt、title、contentHash、行号与实际 source；不返回未经证据支持的模型生成引文。打开引用能看到同一份不可变正文与准确范围；外部缺失来源只显示来源说明。

snapshot 只返回可读资料的有界元数据，不注入全部正文或隐藏文档信息。正文按明确 docId 分页读取。检索、正文与引用打开再次检查共享／来源，Bot 查询记录实际引用依赖；后续模型、工具和发布沿用这些依赖。

资料是供查询的材料，不替代 Bot 的长期记忆或覆盖其身份／系统职责。长期记忆自动带入，资料按需检索；Bot 把资料结论写入记忆时保留来源引用，撤销源权限后该派生内容同样受限制。扩展 memory.write 的可验证 source 可为 `{kind:material,docId,chunkId}`：服务端核对真实不可变块与调用者权限，合并材料的 source／lineage／origins。Bot 的材料查询同样记录 material 依赖；人类编辑已有记忆也保留这些限制，不能自行 supplied origins 清除原来源。

## 4. 共享与封存

新增只读共享范围 `materials`，使用既有 enabled、receivers 与权限上限；资料修改、归档和导入只允许人类或所属 Bot，跨 Bot 的 control 不授予改写别人的资料／记忆。

新建 Bot 默认资料只读共享。迁移后的 Bot 新范围为 `[]`，不从原来的 memory／session 通配符推断新增资料权限；用户在现有共享表单中明确启用。既有关闭／选择性共享和控制撤销保持原意。

从会议独立意见或派生内容形成的资料继承 source、lineage、origins，不能通过检索、正文、引用、摘要或导出绕过封存。升级、归档和内容重复也不消除来源限制。人类可导出自己明确选定、有权查看的资料；Bot 不获得批量导出他人数据的入口。

## 5. 单 Bot 记忆导入导出

初版提供单 Bot 长期记忆的 JSON 导出与导入，不提供整个 profile 或运行态克隆。human-only。导出不含凭据、共享／授权、会话正文、活跃／未知任务、actor、内部绝对路径或材料正文；资料下载只针对单份明确选择的资料。

文件格式声明 `dsh-bot-memory`、formatVersion 1、原 storeId、导出 Bot 的名称和条目正文／分类／固定标记／描述性来源及原 provenance。最多 500 条、总文件 4 MiB，正文各自满足 8192 字符；拒绝未知格式、未知字段、原型键和不合法 JSON 值。导出超过限额时要求明确分批选择，不静默漏条目。

导入先在本地预览条目、重复、来源可验证状态和固定额度冲突；实际提交服务端重新验证完整文件摘要与 target Bot 的 expectedMemoryRevision，不信任浏览器预览。默认仅追加，按规范化正文＋分类摘要跳过完全相同条目；不同内容保持独立记录，不能模糊合并。固定额度超限时需在预览中减少固定项再提交。任何并发记忆修改导致版本冲突时整批拒绝并保留预览，不部分追加。

一次确认一次原子事务，回执保存新增／跳过／不可用 IDs；同 ID 相同原文件重试不重复追加。每条新记忆由服务器分配新 memoryId，来源追加本次人类导入并保留原 provenance。引用用原 storeId 限定，不能将外部环境恰好同名的 Session／task／material ID 解释为本地已验证来源。普通外部来源显示“外部来源说明”，不生成伪链接；具有不可验证跨 Bot／会议保护依赖的条目保存为 inactive，排除 Bot 检索和上下文，直到实际源权限可验证，不以导入丢弃保护。文件中的 botId、memoryId、version、Session ID 或角色标签不能授予身份或访问权，不能伪造原生日志引用。

导入不复活遗忘记录、不覆盖当前内容、不移动记忆归属；用户明确选择的新追加条目与原遗忘标记分开保留。导出和预览零模型请求。

## 6. 接口与验收

新资料 controller 负责 ingest／search／page／archive，新记忆迁移 controller 负责 export／preview-validation／import。PermissionPolicy 增加 material 资源与 materials 只读范围，传递可验证来源。命令帮助明确 read／owner-write／human-only；不存在匿名文件上传或任意 fs 路径入口。

入口放在记忆页的“长期记忆／资料”和“导入导出”折叠区；检索结果链接到资料详情或原生会话，不新增主导航。

必须覆盖：

- 搜索／编辑／分类／固定，多页面旧草稿、额度边界，完整记录预算与实际注入项读取依赖一致。
- 中日韩、单字符、重复词、Unicode 代理对、Markdown 标题、长段落，稳定排序与准确 chunk／行号／正文引文。
- UTF-8／字节与条数额度、归档额度、坏文件与超限原子拒绝；不同同名资料保持独立身份。
- 原生来源不存在／修改／越界／权限不足不允许伪引用；摘取 sealed／revoked 来源的资料不泄漏。
- snapshot 不携带全部正文，检索无权限排名泄漏，正文打开及派生记忆／发布重新检查权限。
- 迁移保持 storeId 和原对象／操作，新增材料共享不扩大，坏／未来 schema 不覆盖，迁移零模型和自动工作。
- 导入预览／提交之间版本冲突，重复文件幂等，来源缺失明确标记，固定超限不部分导入。
- 恶意字段／actor／grants／runtime 数据不能导入，导出不带凭据、运行态或其他 Bot 记忆。
- 禁用／重启／新进程升级后记忆、资料、哈希、引用和权限仍一致。
