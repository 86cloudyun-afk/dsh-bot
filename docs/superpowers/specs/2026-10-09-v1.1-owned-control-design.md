# v1.1 Bot 自身会话管理

状态：按用户授权实施。官方 DSH 0.2.0-rc.2 不改本体，沿用插件五个工作台入口。

认证 Bot 可修改自身名称、职责、联络与执行模型、默认 preset、默认 cwd 和生命周期；配置 CAS、真实模型／preset 校验、原始操作幂等仍有效。其他 Bot 的配置不能仅凭会话控制授权修改。

session.create 扩展 name/model/presetId/cwd 可选项，为已有 Bot 创建联络会话。session.configure 支持会话名称、模型和原生允许修改的 preset；要求会话所有权或当前对应控制授权、expectedVersion、没有真实活动回复／队列／资源。既有 cwd 为官方原生日志头的固定属性，不伪造修改；session.fork 创建名称／模型／cwd 可选的新会话，但保留原 seeded 日志的有效 preset；不同 preset 使用 session.create 建立新会话并保存可验证原会话来源，旧 ID 与历史保留。执行／会议会话的绑定模型、世代、工作目录不能在工作进行中偷换；按任务停止、结算、调整和接续管理。

原生工具默认允许，继续原生审批。plugin_manager 是全 profile 管理，保留工作域边界；裸 subagent 必须走受管任务准入以保存 15 槽、一级子工作和 UNKNOWN 账本。不存在的 session_manager 不虚构 schema。只读 cordis_inspect_list/query 按实际挂载情况可用。

bot.create/delete/restore、跨 Bot 授权和会议阶段继续由工作台操作者管理。单个 Bot 能管理其已有会话与自身配置，不自动取得 profile 全局设置或别人的身份。自己的会话管理包括查询、冷读、发送、停止、归档、恢复、配置、接续和后台任务派发。共享撤销、来源依赖、封存会议屏障、精确停止和 UNKNOWN 不因权限扩展失效。

“嘟嘟”仅为测试具名 Bot，不进入默认数据、提示词或安装包。
