# 使用 DSH Bot

日常创建 Bot 只需填写名称，职责选填、模型默认沿用 DSH。原生工作工具自动可用，无需手动填写工具名。Bot 卡片的“开始聊天”直接进入该 Bot 的新会话；个别模型和目录参数在“更多设置”。

## Bot、会话与长期记忆

在工作台先创建并命名 Bot。新建 Bot 会话只选择已经创建的 Bot；一个 Bot 可以拥有多个会话，每个会话保留自己的聊天历史。

同一 Bot 的身份、长期记忆和未完成任务会自动带入新会话。需要细节时，可以让 Bot 查阅自己的其他会话。记忆按 Bot 分别保存，其他 Bot 的只读访问不会合并或改写它的记忆。遗忘长期记忆保留原始会话日志和来源引用。

在 **Bots → 编辑** 修改职责和模型。工作工具默认沿用 DSH 的权限与审批。需要单独配置任务模型时展开“更多设置”：默认“与聊天模型相同”会自动跟随；明确选定的模型会保持固定。已有配置不会仅因两个模型当前相同而自动改成跟随。另一页面同时修改时，当前草稿保留，保存会检查原版本；点击 **重新载入最新配置** 后再修改。两个 Bot 同名时，界面通过稳定 ID 区分。

## 聊天与后台工作

Bot 的联络会话和工作执行会话分开。把耗时工作交给任务后，仍可继续聊新话题、询问进度、派发短任务、调整目标或要求停止。可以直接用自然语言委派，也可以在工作台操作。

每个 Bot 的父工作、一级子工作和未结算未知工作共用 15 个工作槽。子工作只允许一级；后台工作不会占用独立联络通道。模型服务自身的限流和响应等待仍会显示实际状态。

### 一个任务的完整流程

1. **登记任务**：选择负责人、填写标题和目标。需要指定验收条件或接收会话时，展开“验收与结果接收”。
2. **开始／接续**：启动一个真实工作尝试；**查看执行** 打开 DSH 原生日志。一级子工作可以选择同 Bot 的当前父工作。
3. **调整目标**：展开“调整与接续”。封住旧尝试，待其结算后按新目标接续。任务 ID 保留，新尝试有自己的世代。
4. **停止本次尝试**：停止按钮针对当次尝试。显示“停止已接受”后仍等待真实资源结算；旧停止不会取消后续尝试。
5. **记录验收**：结果结算后展开“验收结果”。结果返回与通过验收分别保存。填写真实证据，选择通过、待定或不通过。
6. **归档／恢复**：已结算任务可归档并恢复。身份、结果和原始日志保留。

结果可回到 Bot 联络会话或普通 DSH 会话。遇到断线或丢回执，“结果与投递”和“待查回的原始操作”保留原身份用于查回。未知工作不会自动重放或提前释放槽位。

## 共享与授权

跨 Bot 默认只读共享本插件管理的会话、任务和记忆。普通 DSH 会话需要人类明确授权给 Bot。

在 **管理 → 共享与授权** 中选择接收 Bot，设置会话、任务、记忆的共享范围，或关闭共享。共享范围是访问上限；持续授权可以在该上限内授予只读或控制权限。控制会话和任务时可以限定具体 ID；权限保存后持续有效，可撤销或降级。

控制权限不包含修改另一个 Bot 的身份、模型、记忆或共享策略。撤销后，新的操作、排队动作和结果发布重新检查当前权限。已经执行的外部动作保留真实历史。

## 内部群与会议

在 **协作 → 内部群** 中选多个 Bot 和协调者，填写群名创建群。轮数与请求预算沿用默认值；需要时展开“群设置”调整。发送消息后，每个成员使用自己的身份和模型产生实际答复。

在群卡片展开“开会”，填入议题和共同材料，点击 **发起会议**。同一群可以同时召开不同议题的会议；各会议的材料、世代和预算分别保存。

会议按以下阶段进行：

1. **独立意见**：各 Bot 先分别形成意见；揭示前不能读取其他参与者的封存意见。
2. **揭示并讨论**：明确进入讨论，成员结合共同材料和已揭示意见发言。
3. **进入决定**：协调者产生实际决定，记录参与者及来源。
4. **登记行动任务**：把决定交给负责 Bot，进入正常任务执行和验收流程。
5. **结束会议**：保留会议记录。取消会议与停止已登记行动任务分开操作。

修改成员或议题会更换相应世代；旧意见和迟到输出不会混入新议题。缺席、失败、预算不足和未知状态分别记录，不冒充全员完成。

## 普通会话、归档与恢复

**管理 → 会话管理** 分页列出普通会话、Bot 联络、工作及群会议会话，包括归档和异常对象。**查看原生会话** 使用 DSH 本来的会话界面；列表本身不会唤醒全部 Agent。

普通会话和 Bot 联络会话正在回复时，可以使用 **停止当前回复**。工作执行使用任务卡片的 **停止本次尝试**。停止当前回复保留原生待处理队列；后续输入继续按 DSH 原生规则处理。

归档保存日志与身份；恢复回到同一对象。未知状态或坏日志需要查回原证据，界面不会建立替代对象假装恢复成功。

禁用、重新启用或卸载后重装插件，正常结算的 Bot 记忆和任务保留。升级步骤见 [安装说明](install.zh-CN.md)。
