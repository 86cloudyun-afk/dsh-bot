# 已作废：旧独立软件版

2026-10-08，用户明确要求全部改为可直接安装到官方原版 DSH 的插件。旧独立应用、Host 装配、SDK 覆盖、owner 启动器、专用 Home/profile、独立网页和相应安装器全部作废，不再支持安装、启动或交付。

这些运行入口已从当前开发分支源码、包导出和打包范围移除。原始代码只在 [冻结历史提交 1f111d7](https://github.com/86cloudyun-afk/dsh-bot/tree/1f111d7f3f5c54127a7523571c8ebc1a738575b8) 中保留以供追溯，不是新插件的安装底座。

历史 Release `v0.1.0-private.1` 及附件属于作废的软件版；旧测试、私有 Host/GUI 证据不计入原生插件验收。不要下载旧安装包作为插件使用。PR #1 保持未合并。

新插件尚在实现与验收阶段；正式交付须满足 [已批准规格](../superpowers/specs/2026-10-08-native-dsh-plugin-v1-design.md) 的 P01–P21，包括多 Bot、记忆、群、真实会议、并发联络、双平台完整安装和审计。
