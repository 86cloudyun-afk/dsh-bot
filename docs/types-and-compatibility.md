# Public declarations and runtime compatibility

This bounded V2 increment adds declarations and `types` routes to the five existing JS-only subpaths. It changes no runtime module, permissions, credentials, network behavior, owner authority, or production binding. The frozen V2 baseline had eleven JavaScript entry points with declaration routes; `./package.json` remains the metadata route.

| Entry | Actual public value contract | Dependency / execution boundary |
| --- | --- | --- |
| `.`, `./plugin` | `Host`, `name`, `inject`, `apply` | Read-only Cordis plugin on fixed official rc.2; an import is not an instantiated Loader, authenticated Host, or GUI proof. |
| `./host` | `Host`, boolean port authenticity / same-Host-owner checks | Local control ledger; private WeakMap retains port ownership; checks expose no metadata. |
| `./bot-read-source` | `createBotTaskReadSource` | Trusted retained owner/resolver required; snapshot uses safe DTO fields; default is `not_configured`. |

Plain Node has no `window`; importing a type route does not prove browser mounting or rendering. |
| `./adapter` | `DshAdapter`, `REQUIRED_NATIVE` | List/inspect pass through scoped ordinary host reads; `complete:false`. Native mutation methods synchronously return `unsupported`. Raw inspect projections are `unknown` until the caller narrows their host contract. |
