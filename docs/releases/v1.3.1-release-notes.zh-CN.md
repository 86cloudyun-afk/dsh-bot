# v1.3.1 · 聊天恢复与多 Bot 状态读取

本版延续原生 Bot 空间，修复五处已复现问题。插件仍安装在未修改的官方 DSH 0.2.0-rc.2 中；schema 2、clientProtocol 2、独立记忆、每 Bot 15 工作槽、一级子工作及可撤销共享保持原契约。

## 修复

- 其他 Bot 的结果通知不可读时，只过滤该通知；当前 Bot 的 `snapshot`、`notice.list`、`briefing` 不再因此整体报 `access_denied`。自己的通知、人类管理视图以及来源撤销检查保留。
- 遗忘人类写入的一条记忆后，不再把另一原操作的不同来源误判为 `forgotten_source`。同一原生日志事件的自动重摄入屏障仍有效；旧回执及遗忘标记不改写。
- 群原生提问／计划的原会话连接恢复失败时，显示明确错误和 **重试原会话连接**。重试只重取同一原生引用，不重发消息、模型任务或工具；已结束请求、旧世代和离开后返回的旧按钮不能复活请求。
- 输入法合成被断线或切换群打断后，新输入可继续发送；迟到的旧合成事件不能影响新输入，正常中文合成 Enter 仍不发送。
- 选择旧聊天或新会话已创建后的 snapshot 读取失败，保留真正的连接错误。成功读取后确实失效的身份仍明确报错，已创建会话不重新创建。

## 安装与历史

[下载插件](https://raw.githubusercontent.com/86cloudyun-afk/dsh-bot/v1.3.1/dist/dsh-bot-1.3.1.tgz) · [校验文件](https://raw.githubusercontent.com/86cloudyun-afk/dsh-bot/v1.3.1/dist/SHA256SUMS) · [中文安装与升级](../install.zh-CN.md)

先备份日常 profile，关闭 DSH，按安装页卸载旧插件再安装本版，重启并刷新浏览器；完整工作台应显示 **插件 1.3.1 / 服务 1.3.1**。原 Bot、记忆、聊天、任务、资料、安排、操作 ID、回执及已有备份保留。旧失败或 UNKNOWN 不自动重放。

新增 v1.3.0 标准升级路径，连同此前九条历史路径分别验证。旧包、标签与证据保持原字节，v1.1.3 仍是历史候选，PR #1 不合并。README 布局图片明确来自 v1.3.0 的真实受控预览，不作为本包重新截图的证据。
