# DSH Bot v1.1.2 · 当前原生插件质量迭代

本轮修复任务调整与结果投递、未来定时规则、插件重载与会话归档、记忆导入来源及工作台迟到读取问题。兼容基线保持官方未修改的 **DSH 0.2.0-rc.2**，继续使用 **schema 2／客户端协议 2**；不要求更换用户 Host，也不引入独立应用。

[安装与升级](../install.zh-CN.md) · [使用手册](../guide.zh-CN.md) · [本版 Release](https://github.com/86cloudyun-afk/dsh-bot/releases/tag/v1.1.2) · [自动验收](../../.github/workflows/ci.yml)

## 本轮行为修复

- **任务与结果**：内容和负责人均未改变的调整保留原版本、验收及活动尝试；旧调整重查不能停止后来启动的工作。并发负面查回和迟到应答错误不能覆盖匹配原消息／会话／日志序号的已接受投递证据，没有证明的请求仍为 UNKNOWN。
- **定时**：修改未来规则不阻止已准入任务按原配方与原回执投递结果，投递时仍检查当前来源和授权。禁用状态重新确认后再启用，也会保留并退休确证未准入的旧触发，使未来周期继续；未知或已准入工作不清除、不重放。
- **重载与归档**：重载重新绑定仍由官方 DSH 管理的既有 Bot 联络会话，保持原生所有权与活动不明时的隔离。归档／恢复的结算检查、原生变更与回执落定期间封住新准入；并发冷读接续共用同一原生创建结果。
- **记忆**：确认导入时检查最新原记忆、资料、回执及来源权限；预览后的来源变化不能被旧证明掩盖。本地导入后的再次导出／导入可核对原始归属，避免反复增加嵌套历史；文件限额内的合法多来源引用保留完整。
- **工作台**：更换／取消导入、最新资料查询、显示全部资料、会话分页、诊断选择与离开页面都隔离旧读取及旧错误。目录刷新合并期间新增的待查回操作和保留历史；取消读取不丢弃已经接受的写入 ID 与回执。
- **交付入口与验收门槛**：移除遮盖仓库根 README 的过时副本，当前入口指向本版。门槛校验完整的具名报告、源码和包身份、退出清理与真实升级记录，不能用数量相同的任意布尔项目代替。

具名 Bot、独立记忆、Bot 自身会话管理、默认可用的已挂载原生工具、preset／审批／目录限制、可撤销跨 Bot 授权，以及每 Bot 15 槽和一级子工作边界保持有效。模型输出已返回、结果投递已接受、验收通过及资源真实结算分别保存。

## 复核范围与证据边界

本轮以当前原生插件的访问／来源、任务／群／会议／投递、定时／会话／资源／恢复、界面和分发验收为源码复核范围。确认的问题以官方 SDK 的实际会话、日志、消息、资源和操作回执复现，再验证修复。独立分项复审与整分支复审是发布门槛，完成状态以最终集成记录为准。

本轮使用受控提供者驱动官方 DSH 的原生请求；新增安装检查使用真实浏览器操作、真实认证 RPC 和原始原生结果。定时修改、重载和归档竞争的专项证据来自官方 SDK 回归，不冒充新增 GUI 操作。未发起外部真实模型请求，未访问或升级用户正在运行的 Host；停止接受不能证明任意不响应终止的生产者或故障资源已经结算。

历史公共清单审计覆盖当时列出的 27 个公开分支／标签端点及 PR #1 历史，合计核计 250 个独立提交、1,523 个独立 Git blob；递归归档检查产生 28,799 次文件扫描、399,454,833 字节（包含重复嵌套文件）。签名扫描未发现所检类型的高置信凭据，历史材料包含构建路径。该结果限于列明的历史清单、内容与签名，不保证任意编码或所有未来引用均无秘密，也不认证历史修改 Host 的全部许可。

旧独立软件继续作废，PR #1 保持关闭未合并；旧分支、历史与归档资产保留，部分原始链接仍可读取，但均不受支持、不参与当前交付或安装。当前插件使用 MIT 许可，不重新分发 DSH 及其依赖。公共验收只输出允许的错误类型／代码与指纹；原始日志、鉴权信息和升级状态保留在私有验收目录。

Bot 名称由用户指定；“嘟嘟”是合法的用户自选名称，不是生产默认身份。UNKNOWN 和原始操作 ID 保留，不用替代任务或重试模型请求掩盖不确定性。
