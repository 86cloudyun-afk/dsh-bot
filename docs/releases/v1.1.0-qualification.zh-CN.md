## 发布条件

正式发布必须同时通过 PR 最新提交的 Linux／macOS × Node 22／24 回归、冻结包复核，以及两平台使用上述同一哈希的全新官方 profile 安装和完整 Chromium GUI。GUI 保留既有 80 项检查，并验证新资料、记忆导入导出、依赖／交接、模板、简报、定时及原生会话配置／接续。

两平台还必须分别从固定 v1.0.0、v1.0.1、v1.0.2 包升级并完整重启宿主，核对实际关闭后持久状态与迁移备份、原身份／回执、真实已结算任务／结果投递及原生日志，确认原操作查回不重放。每条升级包含 7 项检查。CI 报告记录平台、源码提交、包哈希、受控请求与真实请求；本地候选记录不替代最终同包 CI。Release 链接提供发布时已通过的具体 CI 记录。

## 复审关闭的问题

修复了定时投递在控制授权撤销后仍可能继续、原任务开始回执遗漏执行会话／固定输入权限、显式资料来源丢失实际写入会话的限制、长身份文本挤掉必要指令、普通原生工具活动未计入配置屏障、接续 preset 与真实历史不一致等问题。

实际安装还定位并修复标题在原生会话正式登记前改名、插件依赖作用域缺少投影服务、关闭期间未等待配置回执、连续创建记忆／安排使用旧编辑身份、已有阻塞触发丢失一次补跑窗口，以及清理历史破坏原结果重试授权。实际浏览器验证进一步修复上传文本的换行归一化；未编辑的 UTF-8 文件保留原始 CRLF／CR／LF 和 BOM、哈希及引用位置，真实编辑则形成对应的新内容。回归保存真实身份与原始回执；拒绝操作不会重放未知工作。

## 实际边界

Bot 的自身配置和自有会话可管理；跨 Bot 继续使用当前共享及控制授权。原生工具默认使用该会话实际挂载的工具，DSH 审批保持有效；全局插件／身份／授权管理由工作台操作者负责。旧会话目录固定，带历史的接续继承该历史的有效 preset；需要另一 preset 时新建空白会话。资源身份不能证明的普通旧会话明确拒绝配置，不能推测其已经结算。

DSH 关闭时不执行定时任务；补跑有一次固定 60 秒准入窗口，重复重启不延长，UNKNOWN 不自动重放。资料支持 UTF-8 文本／Markdown 的词法检索和原文引用，上下文预算按字符衡量。

本轮没有外部真实模型请求；受控原生模型、真实 Bash／后台进程／终端与停止证据分别记录。历史真实模型结果不作为本版重测。未访问或升级用户自己的 DSH 宿主，也未重放其现场原操作。公开证据省略凭据、认证 URL 和原始宿主日志。此前独立软件版继续作废，PR #1 未合并。
