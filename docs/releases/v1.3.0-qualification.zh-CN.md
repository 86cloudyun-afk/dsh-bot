# DSH Bot v1.3.0 · Bot 空间验收记录

本版为直接安装到未修改官方 **DSH 0.2.0-rc.2** 的原生插件，保持 **schema 2／客户端协议 2**。专用 Bot 空间提供具名多 Bot 私聊、原历史接续、内部群、会议、原生待处理操作与真实行动任务；完整工作台继续承担高级管理。

**本页当前记录工程候选的已知证据。源码完整回归与官方 SDK 检查已通过；最终冻结包、两平台 GUI、九条升级及发布核对尚未全部完成，不能认定 v1.3.0 已交付。** 局部通过的检查和真实截图保留其原始范围，不改标为后续源码或正式发布证据。

## 本版能力与检查范围

- **私聊连续性**：按稳定 Bot／会话身份选择原聊天；浏览不创建会话，显式开始新对话。切换后的迟到结果不能打开旧选择；各 Bot 独立记忆，后台任务与联络聊天分离。
- **专用空间**：左侧列表、中央对话和右侧上下文，沿用官方主题。窄屏抽屉可用 Esc 关闭并返回触发按钮；管理入口定位原 Bot、记忆、任务、群与会议。
- **真实群轮**：成员按轮数与预算在各自原生会话中回复。停止针对确切群轮，停止被接受和资源实际结算分别记录。群新消息上限同时约束人类消息与成员回复；未发布的在途结果保留原日志。
- **原生交互**：工具审批、问题答复／取消和计划同意／修改／拒绝使用原生入口；计划显示完整原文。空间外层关闭只隐藏显示；带原始调用 ID 的原生面板收起后可重开同一未答请求，无 ID 请求的原生放弃会取消，不能重开。超时接续只接受当前有效、未结算的原生问答，旧请求不复活。
- **会议到行动**：先封存独立意见，再明确揭示、讨论和决定。取消未揭示会议仍保留封存；行动任务先登记，再明确开始。群上下文只列出本群会议的行动任务。
- **权限与恢复**：跨 Bot 默认只读，持续共享和控制授权可撤销。每 Bot 15 工作槽、一级子工作、原 ID 与持久回执保留，UNKNOWN 不自动重放。

## 完整升级与发布门槛

九个来源版本为 **v1.0.0、v1.0.1、v1.0.2、v1.1.0、v1.1.1、v1.1.2、v1.1.3 候选、v1.1.4、v1.2.0**。旧包、历史标签和发布资产保持原字节；v1.1.3 仍为历史候选。升级须证明原 Bot、记忆、会话、任务、资料、安排、操作 ID、回执、原生日志和已有迁移备份继续保存。

最终验收需要同一冻结包完成 Linux／macOS 的真实安装 GUI 和九条升级，并以各实际检出的源码核对完整具名检查、历史包、迁移证明及退出清理。两平台完整报告包含一份全新安装报告和九份升级报告，共十份；单条检查通过不能补齐缺失报告。

正式发布还需各自验证最终分支、PR、合并后 main 和精确标签的实际 CI，完成多角度复审，再核对公开源码、安装包、校验文件与匿名下载。最终提交、PR、CI run 和发布身份由 [v1.3.0 Release](https://github.com/86cloudyun-afk/dsh-bot/releases/tag/v1.3.0) 记录，本页不会猜测未来身份或把先前报告重标为最终提交。

## 交付边界

插件复用官方模型、凭据、工具、审批、会话和存储。MIT 插件包不重新分发 DSH／Host／SDK 及其依赖；Bot 空间是 DSH 内的专用面板。已执行操作保留真实历史，停止、取消、结果返回与验收分别记录。

旧独立软件版继续作废，PR #1 保持关闭且未合并；历史分支与归档保留供追溯，不参与本插件安装。完整验收或最终发布尚未确认的事项，保持上述明确状态，不以预览图或局部结果替代。
