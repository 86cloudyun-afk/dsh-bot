## 本版能力

- **持续私聊**：选择具名 Bot 继续自己的原生聊天；浏览不创建会话，明确点击才开始新对话。各 Bot 独立记忆，工作执行与联络聊天分离；切换后的迟到结果不能打开旧选择。
- **专用空间**：左侧 Bot、旧聊天和群，中央对话，右侧任务、记忆、会议与原生待处理操作。沿用官方深浅主题；窄屏抽屉支持 Esc 和返回触发按钮的焦点。
- **真实群轮**：成员在各自原生会话中按轮数和预算回复。停止针对确切群轮；停止意图已受理和资源实际结算分别显示，UNKNOWN 不重放。结束后的缺席成员和原因仍可查阅；同名 Bot 的消息、意见和讨论标明短 ID。
- **原生交互**：工具审批、问题答复／取消、计划同意／修改／拒绝复用原生入口，计划展示完整原文。空间外层关闭只隐藏显示；带原调用 ID 的未答面板可重开同一请求，无 ID 请求的原生放弃会取消。超时接续仅适用于仍有效、未结算的原生问答。
- **会议到行动**：先封存独立意见，再明确揭示、讨论和决定；未揭示会议取消后仍封存。行动先登记，再明确开始；群上下文仅列出本群会议行动。取消后保留已揭示决定、已有行动与原草稿，不再接受新行动。
- **权限与恢复**：跨 Bot 默认只读，持续共享和控制授权可撤销。每 Bot 15 工作槽、一级子工作、原 ID 与持久回执继续保存，UNKNOWN 不自动重放。原生工作工具默认可用，实际调用遵守 DSH 权限和审批。

## 多轮复审与失败记录

源代码、权限与停止契约、原生客户端生命周期、实际安装视觉、中文文档和分发闭包分别复审。发现的冷加载空值错误、同名作者无法区分、取消会议仍可新增行动以及结束群轮隐藏缺席记录均已修复并回归；专项独立复验未发现剩余问题。

历史失败报告继续保留：早期 **957** 项回归中两项因目标包尚未生成而失败；旧界面诊断曾出现审批语言匹配错误及成员回复晚于检查期限；早期 CI 的完整计划定位失败为 **150/163**，另一次 PR 重新启用阶段失败为 **162/163**。这些原报告没有改为通过，也没有延长正式检查期限。

重新启用错误在官方环境定位为空选择和空会话引用。修复后的两次独立诊断保持原主会话、操作及成员／会议世代；第一轮在真实首份数据响应仍被暂留时显示正常加载界面，再交付未修改响应，恢复原聊天。该诊断属于前一 `ca6f740…` 包，作为空值修复的原始证据保留；本版 `c93329b…` 包另行完成上述全新安装与完整升级。

本地九条升级首次启动时，私有驱动把新包校验值传给了旧包，初始化按校验条件失败；原失败报告保留。驱动按原包与目标包分阶段校验修正后，九条完整路径通过，产品代码及完整报告门槛未因此放宽。
