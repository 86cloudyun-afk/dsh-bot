# DSH Bot v1.1.4 · 诊断状态与安装验收修复

本版保留 v1.1.3 候选中已审查的原生插件修复，兼容官方未修改的 **DSH 0.2.0-rc.2**，保持 **schema 2／客户端协议 2**。本地完整回归、冻结包、真实已安装 GUI 与七条升级验证已经通过并完成独立复核；正式发布以本版 Release 的最终源码、包哈希和平台结果为准。

## 本版调整

- 会话列表更新后保留诊断面板的展开状态和所选原操作。更换选择或关闭预览后，迟到回复仍不能恢复旧预览或复制入口。
- 增加真实已安装 GUI 回归：延迟投递一份真实、非空的 session.list 回复，选择原操作并展开诊断后释放列表，验证选择与展开状态保留。原有 120 项具名检查继续保留，本版要求 **121 项**全部通过。
- 安装验收按真实 Bot 稳定身份选择与操作对象，不依赖随机 UUID 的排序；保留原 Bot ID、原生日志、原消息与操作回执。
- 继续保留独立记忆、当前来源权限、冷普通会话管理、任务调整的原尝试树停止、子工作原生配置、暂停定时结算、完整模型参数恢复及既有工作台修复。已有只读共享回边按实际权限核验；真正来源循环、撤权和封存会议来源继续拒绝。
