# v1.3.0 · Bot 空间与多 Bot 协作

在官方 DSH 中拥有专门的 Bot 对话空间：左边选 Bot、旧聊天和群，中间持续对话，右边看任务、记忆、会议和行动。私聊使用 DSH 原生会话；群成员各自在真实会话中回复，原有身份与历史继续保存。

本版兼容未修改的 **DSH 0.2.0-rc.2**，Node **`^22.19.0 || >=24`**。Bot 空间是 DSH 内的专用面板，从原侧栏打开；完整工作台继续提供高级管理。每 Bot 独立记忆、15 个工作槽、一级子工作、可撤销授权、知识与定时能力延续原规格。

## 安装与升级

- [下载插件包 dsh-bot-1.3.0.tgz](https://raw.githubusercontent.com/86cloudyun-afk/dsh-bot/v1.3.0/dist/dsh-bot-1.3.0.tgz)
- [下载 SHA256SUMS](https://raw.githubusercontent.com/86cloudyun-afk/dsh-bot/v1.3.0/dist/SHA256SUMS)
- [中文安装与升级](../install.zh-CN.md) · [使用手册](../guide.zh-CN.md)

安装到自己的日常 DSH profile。以下使用 `web`：

```bash
dsh plugin --profile web add ./dsh-bot-1.3.0.tgz --ignore-scripts --strict-peer-dependencies
dsh web
```

从 v1.0.0、v1.0.1、v1.0.2、v1.1.0、v1.1.1、v1.1.2、v1.1.3 候选、v1.1.4 或 v1.2.0 升级时，先保存原 profile 备份、退出 DSH，再按安装说明卸载旧插件并安装新版。重启后在完整工作台核对 **插件 1.3.0 / 服务 1.3.0**。原 Bot、记忆、聊天、任务、资料、安排、操作 ID、回执和已有备份保留。v1.1.3 仍为历史候选；所有旧包与归档继续保持原字节。

## 这次增加什么

- **专用 Bot 空间**：三栏布局、深浅主题、窄屏会话与上下文抽屉。具名 Bot 与状态持续可见，旧聊天按原名称与 ID 打开。
- **日常多 Bot 入口**：在空间创建 Bot 和内部群；仅浏览不创建会话、不调用模型。各 Bot 独立记忆与聊天，群各自保留输入草稿。
- **真正的有界群聊**：按成员、轮数与预算产生实际回复；停止按钮只针对选中的群轮。停止中与真实已结算分别显示，未知状态保留原记录。
- **从会议到行动**：共同材料、封存独立意见、揭示讨论、协调者决定和行动登记，在当前群上下文中完成。行动先登记，再明确开始执行；群列表只展示本群会议的行动任务。
- **群与会议原生交互**：具体 Bot 的工具审批、问题答复／取消与计划确认统一出现在右栏。计划提供完整原文和原生同意／修改／拒绝入口；带原始调用 ID 的未答请求收起后，可重新打开同一个请求；无 ID 请求的原生放弃会取消。空间外层关闭只隐藏显示。仍有效且未结算的超时问答使用原生接续，已结束或失效请求不会复活。
- **任务和管理衔接**：在对话旁开始、停止和查看真实执行；Bot、记忆、任务、成员和会议通道入口打开完整工作台并定位原对象。窄屏抽屉支持 Esc 和返回触发按钮的焦点。
- **历史与草稿保护**：切换 Bot 后迟到结果不接管新窗口；群发送失败保留正文，成功回执只清理原提交草稿。群的新消息上限同时检查人类与成员回复，在途未发布结果保留原日志，已有历史保留。
- **历史视图读取优化**：群消息和会议记录在一次同步读取中复用当前账本副本，减少历史累积后的重复复制。每次新读取仍核对当前权限、来源和撤销授权。
- **冷加载与重新启用**：首份数据尚未到达、选择和会话引用为空时，Bot 空间继续显示加载界面；原会话的身份检查与引用释放保持有效。
- **协作身份与结束状态**：同名 Bot 的群消息、会议意见和讨论附带短 ID；已结束群轮仍显示缺席成员和原因，可查阅原记录。取消会议后保留已揭示决定及原行动任务，关闭新行动入口；已打开的行动草稿保留正文并提示取消状态。

## 使用时的状态

停止被接受表示已保存停止意图，仍须等待真实资源结算；未知工作不自动重放。取消会议先关闭会议流程，原通道和已登记行动任务分别结算；尚未揭示的独立意见在取消后仍封存。创建、执行、结果返回与验收通过分别记录。

原生工作工具默认可用，实际调用遵守 DSH 权限与审批。跨 Bot 默认只读；人类可在工作台设置共享范围与持续控制授权，并随时撤销。插件复用官方模型、凭据、工具、会话和存储，不重新分发 DSH／Host／SDK。此前独立软件版继续作废。
