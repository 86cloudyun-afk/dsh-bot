## 精简后的操作

- 原生工作工具默认沿用 DSH，无需填写工具名单；审批、共享范围和托管子工作规则继续生效。
- 创建 Bot 默认只显示名称、职责、模型；仅填名称即可使用当前 DSH 模型。卡片“开始聊天”直接打开该 Bot 的原生会话。
- 五个主入口：Bots、记忆、任务、协作、管理。群与会议在协作，共享授权与会话、结果管理在管理。
- 任务登记只显示负责人、标题、目标；模型细项、验收、调整、子工作和群会议设置按需展开。
- 多 Bot、独立记忆、共享与撤销、完整任务管理、群和会议全部保留。明确选定的任务模型不会因当前与聊天模型相同而变成自动跟随。
