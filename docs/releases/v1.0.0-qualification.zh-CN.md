## 持续聊天和完整业务流程

真实 GUI 已验证：三个具名 Bot → 分别配置及保存自有记忆 → 选择已有 Bot 创建原生对话 → 后台原生作业持续运行时回复独立新话题 → Bot 通过自然语言自主登记并启动短任务 → 短任务先返回原会话 → 查看原生执行、调整和接续 → 人类记录验收 → 原身份归档恢复 → 停止确切尝试并核对物理心跳停止。

同一最终包还在真实模型 GUI 中完成两个独立内部群、同一群的两个独立会议、各成员的真实独立意见、讨论、协调者决定、完成会议以及登记并执行实际负责人行动任务。意见和行动均有原生执行日志，未用假结果替代模型或业务状态。

两平台受控 GUI 另外覆盖真实 PTY 停止、原生一级子工作描述与查看、普通会话当前回复停止及任务投递、两个浏览器页共用身份、冷启动保持 Bot 模型/记忆且不改全局模型，以及官方插件禁用、启用、卸载和重装保留数据。
