# DSH Bot v1.0.2 · 聊天身份、删除恢复与工具目录验收

本版修复新建 Bot 聊天进入空白原生会话后看不到 Bot 身份的问题，并增加可恢复的删除入口。插件仍安装到官方 DSH，本体和 Host 不作修改。

[安装与升级](../install.zh-CN.md) · [机器可读证据](v1.0.2-qualification.json) · [PR #4](https://github.com/86cloudyun-afk/dsh-bot/pull/4) · [Release](https://github.com/86cloudyun-afk/dsh-bot/releases/tag/v1.0.2)

## 本版行为

- 原生空白会话会隐藏标题区。身份提示因此同时进入原生输入区：发送第一条消息前即可看到“正在与嘟嘟聊天”。已有对话继续显示标题身份，切换、刷新与同名 Bot 均按真实会话绑定区分。工作和协作会话注明用途，删除后的历史会话注明原 Bot 状态。
- Bot 卡片提供“删除”，必须明确确认。删除保留原 ID、记忆、原生历史、任务、授权和操作回执；恢复回到暂停状态，需要单独启用。活动或未知任务、子工作、群轮次、未结束会议、待处理输入和未确认投递会阻止删除。删除期间暂停新的原生准入，不清空队列或伪造停止结算。
- `tools.list` 与 `help.toolCatalog` 展示实际调用会话的原生工具及限制，不再混入其他 Bot 的 preset 工具。`help.commands` 只列插件业务动作；Bash 是另一个原生工具，其可用性取决于当前 preset。配置与原生管理权限沿用现有边界，本版没有开放全局接管或 Bot 自改配置。

## 复审修复与失败保留

后台复审补齐旧修改回执在删除后仍可准确查回、跨 Bot 子工作原生资源检查、以及尚未创建本 Bot 会话的群／会议流程检查。界面复审修复删除后残留旧编辑页，并为确认框增加安全初始焦点、Tab 范围、Escape 取消和返回焦点。已知写入前拒绝与存储结果未知分开显示；实际存储错误不会被误报为“未写入”。

一次本地完整检查读到了测试心跳文件写入中的半段 JSON。测试文件改为同目录临时文件后原子替换，进程、计数、周期和停止断言均保留。随后重新固定最终包并完成完整检查。

[首次远端 CI](https://github.com/86cloudyun-afk/dsh-bot/actions/runs/37940588287)失败记录保留：Linux 在持续原生 RPC 刷新时等待 `networkidle` 超时；macOS 在新聊天真正打开前重新进入工作台，迟到的原生打开动作移走了页面。包冻结提交的[后续 CI](https://github.com/86cloudyun-afk/dsh-bot/actions/runs/37941149671)在 macOS 完成 80 项 GUI 和两条各 4 项升级检查，Linux 仍在相同的过早导航位置失败。测试改为等待明确的原生会话身份与页面就绪，未增加超时、跳过检查或放宽断言；PR 最新提交仍必须两平台同时通过。

## 边界

本轮外部真实模型请求为 0；受控模型、实际原生 Bash/作业/终端和进程停止证据分别记录。历史真实模型证据继续保留，不能当成本版重新实测。

Bot 配置 `bot.update` 仍仅人类可修改，原生管理工具 guards 不变。改变目录或 preset 适用于新会话，不能热改已挂载原生会话。暂停提示当前用于聊天会话；工作与协作标识注明用途，已删除历史均有状态。DSH 审批／只读子会话接管输入区时可能隐藏输入区提示，已有活动会话仍使用标题入口；不宣称所有原生内嵌接管界面都覆盖。

未访问用户的 DSH 宿主或重放用户现场操作。公开报告省略凭据、认证 URL 和原始宿主日志。
