## 本版升级

- **继续已有聊天**：Bot 卡片选择原聊天，显示保存名称与会话 ID，直接打开原生原会话。
- **资料跨块检索**：跨相邻资料块的词和短语也可找到，仍使用原 chunkId、哈希与精确原文引用。
- **协作来源持续有效**：实际消费群回复后继续传递来源依赖，撤权后限制后续衍生读取；缺失来源的旧记录保留，不根据猜测回填。
- **原始操作与刷新恢复**：保存失败时保留草稿并明确请求未发出；已确定提交的回执保持原语义；提交后获取新快照，保留较新的错误和原 ID。
- **停止与提醒修复**：父工作停止同步更新真正持槽的子任务；编辑后恢复单次提醒保留原时间，仅通知一次；已有安排编辑后的重复卡片已修复。
