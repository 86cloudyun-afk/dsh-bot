## 复审与证据边界

原生权限／记忆、客户端生命周期和整分支分别独立复审，已报告的问题均完成修复与回归，最终三组未留下已知阻塞项。复审额外发现并关闭了 React 子组件先执行导致同步连接失败被清除，以及同一通道下一问答载体没有重试入口的边界。构建现在自动同步前端版本与 package.version，检查模式拒绝漂移且不写文件。

早期未公开候选和首次全量运行的版本不一致失败记录保留，未用后续通过覆盖。输入法迟到事件与连接故障分支由真实 SDK 及事件回归覆盖；163 项实际 GUI 流程不等于在浏览器中逐一强制注入这些故障。README 的布局图片明确来自 v1.3.0 的受控实测预览，不作为本包重新截图的证据。

## 稳定发布关口

合并前核对分支及 PR 的原始 CI；合并后核对 main 和精确发布检查点的标签运行。每个平台必须包含完整 11 份报告、233 个命名检查，以及原始包与源码身份。最终发布前必须复核四阶段的原始报告和产物，不以运行列表的绿色图标代替报告检查。

发布后匿名验证稳定 Release、实际下载包、30 个源码文件、中文页面、历史包与标签、PR 状态及原始 CI 元数据。原始 CI ZIP 通过受认证接口取得并核对摘要；不宣称匿名下载过 ZIP。实际结果和运行链接写入 Release 及对应 PR 的发布后记录。
